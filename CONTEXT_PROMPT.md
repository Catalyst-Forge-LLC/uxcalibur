# UXcalibur project context

The owner approved the revised Phase 1 brief on 2026-10-05 and delegated the recommended initial choices. Current phase: Stabilize — bounded developer release, completed. Read the ledger and `docs/PHASE_1_BRIEF.md` for phase, authority, scope, packets, and acceptance.

UXcalibur helps people accomplish goals or improve outcomes through evidence-backed interface changes. Users can select focus areas and exclusions. A focused pass is the default; a detailed specification is explicit. The reusable skill is the product method; the browser fixture is a target being reviewed.

Approved hero flow: choose the app/flow or aspect → define outcome, focus, exclusions and criteria → invoke the repository skill → inspect source and UI → receive cuts → implement a selected cut → verify and save evidence.

This Build delivers P1–P4: a synthetic review inbox baseline; an actual scoped pass; one implemented cut with before/after verification; fresh-copy invocation and truthful usage docs. The fixture job is find/read/return with stable note identity and useful context. Scope excludes branding, editing/storage, and service/backend features.

Stack: native HTML/CSS, strict TypeScript, Vite, Playwright, pnpm, ESM. Development dependencies are private; skill users need their own agent, not this harness. Notes have stable IDs, display titles, summaries, and paragraph bodies. All search terms match across the complete immutable local corpus. Query/detail ID are URL state; no database, account, or model service is introduced.

Decisions: preserve genesis method/domain jobs (D1); ForgeTrail/AppLedger memory (D2); skill-first proof (D3); proof before public sites/service (D4); accomplishment/improvement and user-controlled scope (D5). WHY: demonstrate useful judgment before promising a runtime or hosting surface, and match work to the owner's chosen outcome.

Keep a baseline commit before implementing a cut. Report synthetic evidence as synthetic; a passing fixture check does not measure customer efficacy. Preserve the personal installed skill as a separate installation. Detailed-spec references remain available.
